#  Lista de Tarefas

Aplicativo simples de lista de tarefas desenvolvido com React Native .

## Funcionalidades

- **observa a imagem**: abrindo o app vera a tela inicial com uma imagem do ronaldinho
- **Adicionar tarefas**: Insira título e descrição (opcional)
- **Listar tarefas**: Visualize todas as tarefas adicionadas
- **Marcar como realizada**: Toque no checkbox ou no texto para riscar a tarefa
- **Remover tarefas**: Exclua tarefas com confirmação
- **Estatísticas**: Visualize total de tarefas e quantas foram realizadas
